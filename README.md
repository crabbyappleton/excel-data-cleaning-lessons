# Excel & Data-Cleaning Lessons

A growing collection of beginner-friendly lessons for learning **Excel**, **data collection**, **data cleaning**, and **data annotation**.

## Lesson 01 — Structured data starts here

This first lesson explains the foundation of reliable spreadsheet work:

> **One row = one record. One column = one attribute.**

It contrasts a messy spreadsheet with a clean, annotation-ready table, then provides a short practice activity using the headings:

- Record ID
- Comment
- Topic
- Sentiment
- Reviewed?

Open [`index.html`](./index.html) in a browser to view the interactive lesson page.
